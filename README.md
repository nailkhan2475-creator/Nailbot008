# ربات نیل سایبر 🤖

یک ربات شخصی واتساپ، تک‌کاربره و کاملاً فارسی، ساخته‌شده با Baileys.

## دستورات موجود

| دستور | کاربرد |
|---|---|
| `.منو` | نمایش منوی اصلی |
| `.پینگ` | بررسی سرعت پاسخ‌دهی ربات |
| `.زنده` | بررسی آنلاین بودن ربات |
| `.مالک` | نمایش اطلاعات مالک |
| `.کانال` | نمایش لینک کانال پشتیبانی |

می‌تونی دستورات بیشتری به فایل `bot.js` (تابع `handleCommand`) اضافه کنی.

## اجرای محلی (روی سیستم خودت)

```bash
npm install
npm start
```

بعد از اجرا، آدرس `http://localhost:8000` رو باز کن، شماره‌ات رو بزن و کد پیرینگ رو بگیر.

## دیپلوی روی Render

1. این پروژه رو به یه ریپازیتوری گیت‌هاب پوش کن (پوشه‌ی `session` و `node_modules` به لطف `.gitignore` پوش نمیشن)
2. توی Render یه **Web Service** جدید بساز و ریپازیتوری رو وصل کن
3. تنظیمات Build/Start:
   - **Build Command:** `npm install`
   - **Start Command:** `node index.js`
4. متغیر محیطی زیر رو توی بخش Environment اضافه کن:
   - `OWNER_NUMBER` = شماره واتساپ خودت با کد کشور (فقط عدد)

بعد از دیپلوی، آدرس سایت Render رو باز کن (مثلاً `https://your-app.onrender.com`)، شماره‌ات رو بزن و کد رو توی واتساپ وارد کن.

## ⚠️ نکته‌ی مهم درباره‌ی Render (فایل‌سیستم موقتی)

پلن رایگان Render فایل‌سیستمش **پایدار (Persistent) نیست** — یعنی با هر ری‌استارت یا Sleep شدن سرویس، پوشه‌ی `session` (که اطلاعات ورود واتساپ توش ذخیره میشه) پاک میشه و باید دوباره پیر کنی.

راه‌حل‌ها:
- برای تست و استفاده‌ی کوتاه‌مدت، همین روش کافیه (فقط گاهی نیاز به پیر کردن مجدد داری)
- برای اتصال دائمی و پایدار: از پلن **Starter** به بالای Render همراه با یک **Persistent Disk** استفاده کن و مسیر `session/` رو به اون دیسک وصل کن
- یا اینکه محتوای پوشه‌ی `session` رو (مثل نسخه‌ی قبلی ربات) به یک دیتابیس مثل MongoDB بیرونی بفرستی تا بین ری‌استارت‌ها از بین نره

## شخصی‌سازی بیشتر

- منو و دستورات: فایل `bot.js`
